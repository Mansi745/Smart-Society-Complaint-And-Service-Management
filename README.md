# Smart Society Complaint And Service Management

A full-stack web application for managing complaints and services in a residential society.

## 🚀 Tech Stack

### Frontend
- React.js
- Vite
- Material UI
- Axios
- React Router DOM

### Backend
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- Maven

## ✨ Features

- User Registration & Login
- Role-based Authentication (Resident & Admin)
- Resident Dashboard
- Admin Dashboard
- Raise Complaint
- Complaint Tracking
- Profile Management
- Change Password
- Responsive UI
- Notifications

## 📂 Project Structure

```
Smart-Society-Complaint-And-Service-Management
├── frontend
├── backend
└── README.md
```

## ▶️ Run the Frontend

```bash
cd frontend
npm install
npm run dev
```

## ▶️ Run the Backend

```bash
cd backend
mvn spring-boot:run
```

## 🗄️ Database

- MySQL
- Create a database named `smart_society`
- Update `application.properties` with your MySQL username and password.
